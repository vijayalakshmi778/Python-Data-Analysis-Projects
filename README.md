# Customer Sales Data Cleaning and Analysis

## Project Overview

This project focuses on cleaning and analyzing a customer sales dataset using Python and Pandas.

The dataset contains common data quality issues such as missing values, duplicate records, inconsistent text formats, and different date formats.

## Technologies Used

* Python
* Pandas
* Google Colab / Jupyter Notebook
* CSV

## Dataset

The dataset contains the following fields:

* Order ID
* Customer Name
* City
* Product
* Category
* Quantity
* Price
* Order Date
* Payment Mode
* Salesperson
* Customer Rating

## Data Cleaning

The project includes:

* Handling missing values
* Removing duplicate records
* Cleaning customer names
* Standardizing city names
* Standardizing payment modes
* Converting date formats
* Converting numeric columns
* Creating a `Total_Price` column

## Analysis

Basic analysis was performed using:

* `value_counts()`
* `groupby()`
* `sort_values()`

The analysis includes product-wise, category-wise, and city-wise sales.
